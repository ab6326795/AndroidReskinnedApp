

# Android App上架被误报马甲包、相似度过高处理指南

## 一、马甲包简介

马甲包指同一套代码，套在不同 App 内进行上架。

#### 

#### 为什么存在马甲包？

一些特殊的行业在现行规则下 App 受限，原因可能如下：

1. ASO：单个 App 覆盖的关键词有限，需要多个相同内容的 App 来尽可能覆盖多的关键词
2. 单个 App 能推广到的用户数有限，需要多个相同内容的 App 来提高总用户数

总的来讲，做马甲包是为了扩大用户数来实现营收增长

## 二、普通APP为什么会误报成马甲包？

**哪怕你全程手写原创代码，只是引用了通用开发框架，也可能被平台的自动化检测机制误判 为马甲包**。

手动改包名、调混淆规则、删冗余代码折腾好几天，重新提交还是被打回，不仅上线计划一拖再拖，搞不好还会拉低开发者账号权重，严重时甚至面临封号风险。

这就意味着，你熬了无数个通宵写完代码、调完功能，满心欢喜把APK提交到应用商店，等来的却不是上架通知，而是冷冰冰的驳回提示：**<mark>“代码相似度过高”“疑似马甲包”“应用高度相似或完全雷同”</mark>**。
